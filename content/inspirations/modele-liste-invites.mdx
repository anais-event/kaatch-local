## La réponse tout de suite

Un bon **modèle de liste d'invités** ne se limite pas aux noms. Pour éviter de courir après l'info plus tard, notez aussi : le **RSVP**, les **+1**, le **régime alimentaire**, le **groupe** (famille, amis…), et l'**hébergement** éventuel.

Ces quelques colonnes vous font gagner un temps fou pour le traiteur et le plan de table. 💛

---

## Les colonnes vraiment utiles

| Colonne | Pourquoi |
|---|---|
| Nom & prénom | La base |
| Groupe/relation | Pour le plan de table |
| +1 / accompagnant | Pour le total et le traiteur |
| Enfant (oui/non + âge) | Menu enfant, chaise haute |
| RSVP (oui/non/en attente) | Suivi des réponses |
| Régime alimentaire | Végé, sans gluten, allergies |
| Email / téléphone | Pour relancer |
| Hébergement nécessaire | Pour organiser les nuitées |
| Table assignée | Pour le plan de table |

## Vos petites questions

**Quelles infos noter pour ses invités ?**

Au minimum : nom, groupe, +1, RSVP, régime alimentaire. Ajoutez email/téléphone pour relancer et table pour le plan de table.

**Excel ou outil en ligne ?**

Excel dépanne, mais un outil en ligne compte le total, suit les réponses et se partage. Bien plus reposant dès que la liste bouge (et elle bouge !).

**Quand commencer sa liste ?**

Très tôt : le nombre d'invités détermine la salle, le budget et le traiteur. C'est souvent la toute première étape.
