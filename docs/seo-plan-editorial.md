# Plan éditorial SEO — Kaatch

> Objectif : capter les recherches fréquentes des (futurs) mariés, générer du trafic organique qualifié, et le convertir vers l'app.
> Date : 2026-10-20

---

## 1. Principe directeur

Kaatch est un **petit site jeune** → viser la **tête de requête** ("logiciel mariage") est perdu d'avance à court terme : trop de concurrence, trop lent.

**Stratégie gagnante = longue traîne en masse + maillage interne.**

Chaque article répond à **une question précise** que les mariés tapent déjà sur Google (intention claire), puis renvoie vers **l'outil Kaatch correspondant**. Le visiteur arrive pour l'info → découvre l'outil → s'inscrit.

Règle du maillage : **chaque article = au moins 1 lien contextuel vers une page outil** (`/budget-mariage`, `/checklist-mariage`, etc.) + 1 CTA app en fin d'article.

**Rythme cible** : le SEO décolle vers 40-60 pages de contenu. On est à 10 → objectif **+30 articles** sur les clusters ci-dessous.

---

## 4. Checklist de qualité par article (pour ranker)

Chaque MDX doit avoir :
- [ ] **Titre H1** qui contient la requête cible (naturellement)
- [ ] **`excerpt`** = meta description, 140-160 car., avec le mot-clé + une promesse
- [ ] **Réponse directe dans les 100 premiers mots** (Google aime, + featured snippet)
- [ ] **Sous-titres H2/H3** structurés par sous-questions
- [ ] **1+ lien interne contextuel** vers la page pilier outil
- [ ] **CTA app** en fin d'article (ex : "Gère ta liste directement dans Kaatch →")
- [ ] **800-1500 mots** pour un article, 400-700 pour astuce/bon-plan
- [ ] Ton Kaatch : direct, sans bullshit, concret, chiffré (cf. article budget existant)
- [ ] `date` récente + `readTime` réaliste

## 5. Au-delà du contenu (les 2 autres leviers)

**Technique** — déjà bon (sitemap dynamique, canonical, i18n, Next rapide, mobile). Rien d'urgent.

**Autorité / backlinks** — c'est le **plafond actuel** du ranking. Actions hors-code :
- S'inscrire sur annuaires mariage (Mariages.net, Zankyou, etc.) avec lien
- Partenariats / articles invités sur blogs mariage
- Être cité par des prestataires partenaires (échange de liens)
- Pinterest : énorme sur le mariage → épingler les articles/outils

**Mesure** — Google Search Console (`sc-domain:kaatch.fr`) :
- Onglet **Performances** → trier par impressions : les requêtes où Kaatch apparaît en page 2-3 = cibles prioritaires (petit effort → page 1)
- Suivre le CTR et la position moyenne par article

## 6. Proposition de séquençage

1. **Semaine 1-2** : Vague 1 (8 articles) → trafic transactionnel rapide
2. **Semaine 3-4** : Vague 2 (8 articles) → consolide les piliers
3. **Mois 2** : Vague 3 (14 articles) → complétude + niches
4. **En parallèle** : backlinks (annuaires + Pinterest) dès maintenant
5. **Mois 2-3** : audit GSC → optimiser les pages qui montent

Résultat attendu : premiers gains organiques à 4-8 semaines sur la longue traîne, montée en puissance à 3-6 mois.
